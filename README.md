# 32 吋雙螢幕選購筆記

繁體中文靜態研究網站，針對台灣購買兩台同款 31.5／32 吋級、平面、原生至少 3840×2160 且至少 60Hz 的螢幕，整理規格、通路與長時間閱讀的證據。

- 網站：https://river-ye.github.io/32-inch-monitor-guide/
- 查核日期：2026-10-27（Asia/Taipei）
- 使用條件：Windows／macOS、一橫一直、FUNTE Arco 單臂兩支、180×80×3.3 cm 桌板。

## 使用與資料

原生 HTML、CSS、JavaScript，無建置步驟、第三方執行期套件、追蹤碼或外部字型。

`products.json` 分開保存型號規格、賣場資訊、證據來源與查核範圍。每項供貨、價格與保固僅屬於其賣場；搜尋索引及估價單參考價均標示，不能證明有貨。未知數值使用 null，不以零或推算值填補。

網站可搜尋、篩選、並排比較最多三款，查看原始來源及賣場。雙台費用為單價乘二估算；所有查得賣場均尚未確認兩台供貨數量。幾何示意採兩台間距 2 cm 的平面外廓，不代表支架、桌下結構、接頭或旋轉淨空已通過。

## 研究邊界

本次建檔 194 個型號／區域或表面版本、23 個品牌、312 筆來源。這是列明範圍的研究快照，不能宣稱涵蓋市場上每一款產品。各品牌型錄、通路關鍵字與分頁的處理狀態均在網站公開。

PChome 已讀取「32 4k」搜尋索引 42 頁，840 筆搜尋結果；部分商品頁遇 429 後停止。蝦皮等來源存取受限；部分品牌與通路仍有未涵蓋範圍，詳見查核台帳。無法確認的候選保留待確認，明確不符合基本條件者另列排除。

獨立實測只採可公開讀取的精確受測型號結論，不跨型號搬用，也不補造會員內容。原廠低藍光、防閃爍與亮度宣稱和實測分開呈現。未指定實際 Mac 或 Windows 主機，因此雙台輸出能力尚未驗證。

## 本機預覽與檢查

需 Node.js 內建測試執行器與 Python 3；不需安裝 npm 套件。

```sh
node --test *.test.mjs
node --check app.mjs
python3 -m http.server 8765 --bind 127.0.0.1
```

開啟 http://127.0.0.1:8765/ 。GitHub Pages 使用 main 分支根目錄，`.nojekyll` 保留原生靜態檔案。

## 更新方式

更新 `products.json` 中的型號、各賣場時間與原始來源，維持 source ID 引用與 unknown 判定，重新執行資料及邏輯測試，再檢查 Chrome 互動／手機版、部署後公開資產版本。價格或缺貨變更不應改寫其他賣場的保固。
