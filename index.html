BEFORE THE SECOND SCREEN

買兩台之前，先對齊這三件事。

01 / 文字與方向

看實際的字，再逐台設定。

LCD 與 OLED 都保留在清單。文字清晰度、反光、亮度及閃爍都看精確型號證據；OLED 的靜態內容、像素結構與保固另有取捨。

Windows：設定 → 系統 → 顯示器，先選那一台再調整縮放、原生解析度及橫／直向；進階顯示器逐台核對訊號解析度與 Hz。macOS：系統設定 → 顯示器 → 選外接螢幕 → 旋轉 90°／270°，選項依螢幕而異。

先查螢幕文件確認直立操作安全，再讓系統排列與實體位置一致。

02 / 接線

雙台輸出，先查主機上限。

Windows 顯示卡與 Mac 晶片各有同時外接台數、解析度及 Hz 組合限制；擴充座不會增加晶片原生上限。目前主機、顯卡與擴充座型號未指定，雙 4K／6K 輸出尚未驗證。

macOS 不支援以 DisplayPort MST 取得兩個不同延伸桌面；Thunderbolt 路徑須另查主機與擴充座支援圖。USB-C 主機、螢幕、線材與轉接器須支援 DP Alt Mode 或合適 Thunderbolt 影像能力，充電瓦數無法單獨證明。

兩台各接一個獨立影像輸出，仍須核對主機同時輸出組合；每條路徑皆須達目標原生解析度與更新率。

03 / 安裝

重量符合，還要確認淨空。

Arco 單臂原廠標示承重 2–27 kg、VESA 75×75／100×100、螢幕旋轉 ±90°。以拆底座後加轉接件的實際負載核對；重量落在範圍內只代表重量條件。

3.3 cm 桌板位於夾桌 1.2–4.5 cm 厚度範圍；桌板結構、桌架與夾具空間仍待現場核對。180 × 80 cm 桌面的一橫一直外廓估算可見各型號資料。

原廠未公布最大 VESA 中心高度與臂長，不能確認直立 32 吋不碰桌或兩臂可完全收合；接頭、線材與實際觀看距離也待量測。
